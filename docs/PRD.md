# Media Studio 产品需求与原型标准 v0.1
更新时间：2026-10-24

## 产品定义
一个工作台完成选题、AI 辅助写稿、多模态素材、图文视频排版、模板渲染、多账号适配、审核、定时/立即发布、结果回执、数据分析。Java 与 Rust 完全同构，产品原型为独立验收基准。

## 导航结构与能力清单
1. 总览：今日待办、账号状态、成功/失败任务、近 30 天趋势、待授权与待审核。
2. 内容中心：文章/笔记/短帖/视频稿，Markdown 与富文本编辑、自动保存、版本比较、回滚、评论、草稿共享。
3. 模板中心：微信公众号深色科技排版、公众号简约、种草笔记、知识长图、短视频脚本、新闻资讯、营销海报、通用图文。模板参数包括文字层级、封面、Logo、水印、正文样式、字体许可、色板、段落/卡片/引用。
4. 素材库：上传和文件夹、图片/视频、EXIF/版权记录、标签、去重、裁切、缩略图、批量重命名、存储、站点水印、平台尺寸转换及预览。
5. AI 工作台：选题调研、标题组合、改写扩写、敏感表述提示、不同平台语气/字数转换、封面文案、SEO、来源校验、人工确认。模型可配置，不保存明文 API Key。
6. 账号矩阵：多个平台多个账号、OAuth 或平台合法授权、权限范围、令牌过期预警、账号分组、组织和角色。
7. 多端预览：公众号、小红书、微博、知乎、抖音/B站说明、网页；封面安全区、比例、字数、链接、话题、图组与差异标记。
8. 分发中心：选择平台/账号、逐平台变体、预检、立即/排期、幂等发送、异步队列、限流、重试退避、部分成功独立回执、取消未启动任务、手动交付包。
9. 内容日历：拖动排期、重复活动、节假日编辑计划、时区、审批依赖。
10. 审核与协作：RBAC、撰稿/设计/审核/运营/管理员、四眼复核、操作审计、变更痕迹。
11. 统计与复盘：渠道链接、平台允许的官方指标、导入报表、失败原因、文章复用与 A/B 测试；不编造不可访问数据。
12. 系统设置：对象存储、数据库、工作空间、Webhooks、健康检查、备份恢复、隐私合规与数据导出。

## 关键体验
- 「一键分发」含一键发起 *多个独立平台任务*，不得声称原子性全成功。
- 每个平台任务须显示：DIRECT_API / AUTHORIZED_PARTNER / HANDOFF / UNSUPPORTED；账号授权状态；预检；回执。
- HANDOFF 必须有可下载/复制的正文、封面及图片包和发布核对步骤；不假装发布成功。
- 统一产品界面；Java 与 Rust 只切换后端服务，前端契约不变。
- 无密钥演示模式一眼可辨，不记作平台真实验收。
- 内容和素材分开保管；内容删除、撤稿和发布历史有审计。
- 图文优先，视频预设与脚本齐备，视频真实转码与上传须专项验收。

## 数据实体
Workspace, User, Role, SocialAccount, Authorization, Content, ContentRevision, Template, MediaAsset, ChannelVariant, Approval, PublishBatch, PublishJob, PublishAttempt, PublishReceipt, MetricsSnapshot, AuditEvent.

## 非功能
OpenAPI、幂等键、对象存储与数据库迁移、时区、访问控制、输入净化、跨站请求保护、Secret Manager、可观测性、队列积压报警、备份恢复、可访问性与移动适配。
